A structured exploration of foundational algebraic concepts, linear systems, and mathematical logic implemented in modern Python. Built as part of the **Modern Legacy** engineering initiative to bridge classical mathematical principles with software engineering and data analysis.

---

## 🎯 Key Focus Areas

- **Linear Systems & Equations:** Computational solutions for linear systems, coordinate transformations, and functional dependencies.
- **Polynomial Transformations:** Symbolic manipulation, polynomial expansions, and factorization algorithms.
- **Functional Analysis & Visualization:** Interactive 2D/3D visualizations of algebraic functions and equations.
- **Reactive Computing:** Utilizing `Marimo` reactive notebooks (`.py` scripts) for reproducible, state-safe mathematical workflows.

## 🛠️ Tech Stack

- **Language:** Python 3.11+
- **Environment:** [Marimo Notebooks](https://marimo.io/) (Pure Python reactive environment)
- **Mathematical Libraries:** `SymPy`, `NumPy`, `Matplotlib`, `Plotly`

## 🚀 Quick Start

Clone the repository and launch interactive notebooks locally:

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/applied-algebra-python.git
cd applied-algebra-python

# 2. Install dependencies
pip install marimo sympy matplotlib numpy plotly

# 3. Launch an interactive Marimo notebook
marimo edit <notebook_name>.py
