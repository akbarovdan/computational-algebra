A structured exploration of foundational algebraic concepts, set theory, linear systems, and mathematical logic implemented in modern Python. Built as part of the **Modern Legacy** engineering initiative to bridge classical mathematical principles with software engineering and data analysis.

---

## 🎯 Key Focus Areas

- **Set Theory & Logic:** Formal set definitions, subset relations, domain evaluation, and Boolean operations.
- **Linear Systems & Equations:** Computational solutions for linear systems, coordinate transformations, and functional dependencies.
- **Polynomial Transformations:** Symbolic manipulation, polynomial expansions, and factorization algorithms.
- **Interactive Computations:** Utilizing `Jupyter Notebooks` (`.ipynb`) for reproducible, structured mathematical workflows.

## 🛠️ Tech Stack

- **Language:** Python 3.11+
- **Environment:** [Jupyter Notebooks](https://jupyter.org/) (`.ipynb` in VS Code)
- **Mathematical Libraries:** `SymPy`, `NumPy`, `Matplotlib`, `Plotly`

## 🚀 Quick Start

Clone the repository and launch interactive notebooks in VS Code or Jupyter Lab:

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/applied-algebra-python.git
cd applied-algebra-python

# 2. Install dependencies
pip install jupyter ipykernel sympy matplotlib numpy plotly

# 3. Open .ipynb notebooks directly in VS Code
